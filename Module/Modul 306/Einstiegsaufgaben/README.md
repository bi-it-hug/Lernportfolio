# Einstiegsaufgaben

### 1. Was ist ein Projekt?

Ein Projekt ist eine Unternehmung mit einem klar definierten Ziel.

### 2. Ist alles was man macht ein Projekt?

Nein, alltägliche Aktivitäten gehören nicht dazu, da ein Projekt zeitlich begrenzt ist und ein spezielles Ziel verfolgt.

### 3. Wer gehört typischerweise zu einem Projekt?

Typischerweise gehören Projektleiter, Teammitglieder und ggf. Stakeholder zu einem Projekt.

### 4. Wo habe ich schon Projekte angetroffen oder wer sagte schon mal was über ein Projekt?

Im Geschäft bin ich aktiv an einem Projekt beteiligt, bei dem wir eine neue Softwarelösung entwickeln.

### 5. Wie kann ich ein Projektziel formulieren?

Ein Projektziel sollte den Wunsch des Kunden berücksichtigen und klar, messbar sowie erreichbar formuliert sein.
