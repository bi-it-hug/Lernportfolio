# Datenbanken

## ERD / ERM

-   **ERD**: Ein Diagramm, das die Beziehungen aller Tabellen darstellt, mit definierten Primär- und Fremdschlüsseln.

-   **ERM**: Ein Diagramm, das ebenfalls die Beziehungen aller Tabellen darstellt, jedoch mit dem Unterschied, dass das ERM eine Art Skizze des ERD ist und noch keine definierten Schlüssel hat.

## ID / IDFS

-   **ID**: Eine eindeutige Kennung, die verwendet wird, um Datensätze in einer Tabelle zu identifizieren.

-   **IDFS**: Ein Fremdschlüssel, der auf eine ID in einer anderen Tabelle verweist und somit eine Beziehung zwischen den Tabellen herstellt.

## Assoziationen

-   **1:1 Beziehung**: Eine Beziehung, bei der ein Datensatz in Tabelle A genau einem Datensatz in Tabelle B entspricht.

-   **1:n Beziehung**: Eine Beziehung, bei der ein Datensatz in Tabelle A mehreren Datensätzen in Tabelle B entspricht.

-   **n:m Beziehung**: Eine Beziehung, bei der mehrere Datensätze in Tabelle A mehreren Datensätzen in Tabelle B entsprechen.

## Beziehungspaare

-   **Primärschlüssel (PK)**: Ein Attribut oder eine Kombination von Attributen, das jeden Datensatz in einer Tabelle eindeutig identifiziert.

-   **Fremdschlüssel (FK)**: Ein Attribut oder eine Kombination von Attributen in einer Tabelle, das auf den Primärschlüssel einer anderen Tabelle verweist.

## UN / NN

-   **UN (Unique)**: Ein Attribut, das für jeden Datensatz in der Tabelle einen eindeutigen Wert haben muss.

-   **NN (Not Null)**: Ein Attribut, das für jeden Datensatz in der Tabelle einen Wert haben muss und nicht leer sein darf.

## Diagramm zeichnen

-   **ERD-Tool**: Verwenden Sie ein ERD-Tool wie Lucidchart, draw.io oder ein anderes Diagrammwerkzeug, um Ihre ERD- und ERM-Diagramme zu erstellen.

-   **Schritte**: Identifizieren Sie alle Entitäten, definieren Sie die Beziehungen zwischen den Entitäten, fügen Sie Primär- und Fremdschlüssel hinzu und stellen Sie sicher, dass alle Beziehungen korrekt dargestellt sind.
